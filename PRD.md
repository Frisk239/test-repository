# PRD: Parking-Lot Login Page

## Objective
Provide a login page for the parking-lot system so staff can authenticate before managing parking operations.

## Requirements
- Users must be able to enter credentials and log in to the parking-lot system.
- The login page shall be the entry point of the parking-lot application.
- A minimal CLI version shall print the identifier `parking-login` to confirm the login module is wired in.

## Acceptance Criteria
- `src/app.py` runs and prints `parking-login`.
- The login flow is reachable as the entry point of the application.
